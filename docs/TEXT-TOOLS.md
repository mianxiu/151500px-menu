# 文本工具

在 Caps 中编辑一个文字图层，预览处理结果，再一次写回或拆成多个可编辑文字层。0.4.264／UXP0.3.71实现；公开下载状态见 [Wiki Versions](https://github.com/mianxiu/151500px-menu/wiki/Versions)。

## 开始前

单选未锁定的文字图层，在 Caps 圆环左侧点击“画布排版”。本工具生成的智能对象从左侧的“文字源”进入同一窗口。多选或无法确认目标时不提供入口。拖动顶部“画布排版”标题可移动窗口。拖动窗口外缘或角落可调整窗口大小，右上角按钮用于最大化、还原或关闭。

0.4.445 候选在收到正文和样式后即可编辑草稿。“正在读取背景…”显示独立的取图进度。Generator 未连接、取图失败或文档超出取图范围时，仍可选字、编辑和撤销。“重试背景”保留当前草稿。可定位的画布背景就绪后，结束当前文本输入即可回到图上编辑。若 Photoshop 的目标或历史发生变化，草稿保留，提交须先重新读取当前文字。

原生文字仍在编辑时，确认写回会先保留并确认当前 PS 文字编辑，再执行文本事务（需实际加载 UXP0.3.96）。若提示最新内容与预览不同，使用“重新读取文字（覆盖草稿）”获取已保留的最新文字，检查后再写回。变换、其他工具模态或目标变化不会自动确认；请先完成相应操作。读取与预览本身不自动结束原生编辑。

## 画布排版

在中央画布上选中文字或放置光标，然后用左栏的“字符”和“段落”设置排版。可以按文字选区、当前段落或整层应用。字段会显示原值、自动、继承或混合，留空或选择“沿用”会保留原值。右栏集中放置文字处理、表格和写回操作。右上角的方框、重叠方框和叉号分别对应最大化、还原和关闭，悬停可查看名称。

0.4.440 起，作用范围默认“自动”。字符样式作用于选中的字符，无选区时用作之后输入的样式。段落设置作用于选区覆盖的整段，无选区时作用于光标所在段落。一份草稿可保留多个范围的不同设置，重选文字会读回该范围的值。可以在“样式预设”里分别保存和应用字符或段落参数。预设存于本机，应用后进入当前草稿。

排版窗口的预览在本机生成。关闭会丢弃尚未确认的正文和样式草稿。按右下角的生成、更新或拆分按钮才会提交修改。工具保留背景、背景颜色、缩放和作用范围，“恢复排版视图默认设置”重置这四项。

0.4.430 本机候选保留失焦时的排版窗口和草稿。切回所属 Photoshop 工作区后可继续编辑，提交前仍按原文档和图层核对。选区样式在调整时应用到选定范围，之后点击画布移动光标会保留草稿里的该范围。

- “字符”可搜索 Photoshop 已识别的字体族并单独选择样式，还可设置字号、自动或固定行距、度量或视觉字偶间距、字距和文字颜色。取色适用于 sRGB 8 位文档。
- 在画布上选中文字后，可直接在“字体”和“样式／字重”中选用 Photoshop 已识别的字体变体。未手动指定应用范围时，换字体或字重应用到当前选区。
- 字体族和字重下拉项使用对应的本机字体显示样本。样本取画布选区，无选区时取正文开头。将鼠标停在候选上，可在中央画布查看本地字体效果，移开恢复原草稿，点击选定字体。常用字符与段落字段用图标标识，悬停图标可查看字段名称。
- 在“手动字偶”处，把光标放在同一段的两个字符之间，再输入 −1000 至 1000。单位为 1/1000 em。0 是显式零字偶值，“恢复自动字偶”移除该对字符的手动值。已有字偶随保留的相邻字符一起移动。带手动字偶的图层暂不支持拆分。
- 点击“进阶字符”或“OpenType”中的开关图标可开启或关闭该选项。高亮表示开启，角标短线表示混合或继承，悬停可查看名称和当前值。点击组尾回退图标即可沿用本组开关的原值。数字样式通过下拉选择，实际字形变化取决于所选字体。
- 展开“更多字符设置”可填写 PostScript 名称，以及设置水平／垂直缩放、基线偏移、上下标、大小写、仿粗／斜体、下划线、删除线、标准连字和禁止换行。固定行距和基线偏移以 pt 计，字距以 1/1000 em 计，缩放以百分比计。
- “段落”提供左对齐、居中、右对齐和四种两端对齐，按涉及的整段应用。水平段落文字可设置左右和首行缩进、段前／后距及自动断字。高级段落选项包括逐行或全段排版、罗马标点悬挂、断字条件，以及两端对齐的词距、字距与字形缩放范围。列表沿用自身的对齐和缩进规则。

普通段落文字按 Photoshop 文字框的实际位置和尺寸编辑。单击或选择字符时，文字显示与框宽保持稳定。拖动左边或右边调整宽度，对边保持原位。拖动底边调整高度，底部两个角可同时调整宽高。具有可调段落框的矢量文字对象也支持这些操作。滚轮缩放，拖动空白区域或按住中键平移，点击“适合窗口”复位。背景图最长边为 2048 像素，文档上限为一亿像素。变形文字等无法定位编辑框的图层可以在同窗右侧编辑正文。

画布工具栏提供“文档背景”“透明背景”和“纯色背景”。后两种视图只显示当前排版对象，选择“纯色背景”后可用旁边的色块选色。背景选项只用于窗口显示。

框内可继续输入、选字，使用 Ctrl+Z 撤销、Ctrl+Y／Ctrl+Shift+Z 重做。正文、样式和文字框调整留在草稿中。画布的本地草稿可以查看字体、颜色和排版变化。换行、字偶、字形及对齐以写入后 Photoshop 的实际排版为准。

放大只调整窗口的本地视图。普通文字点“生成矢量智能对象”，已有对象点“更新矢量智能对象”。一次 Photoshop 撤销可恢复写回前的排版。

水平单栏、未变形的普通段落文字和具备段落框的原生 PDF 文字对象，可在“段落”里修改左缩进、右缩进和首行缩进。首行可以输入负值。留空保留原值，输入 0 清零。工具生成的列表由列表层级控制左缩进和首行悬挂缩进，右缩进可在段落页调整。

矢量文字的源画布应与当前文档尺寸、分辨率一致。保存分层 PSD 可保留同层的可编辑文字源。[矢量文字对象](TEXT-VECTOR-OBJECTS.md)

### 独立表格

本机候选 0.4.408／UXP 0.3.120 支持在 RGB 8 位文档中创建独立表格。

1. 单选未锁定的文字层，从 Caps 打开“画布排版”。在右侧选择“表格”。
2. 在右侧格子中输入内容。默认两行两列，可以添加行或列，也可以移除末行、末列。每张表支持 1–12 行、1–8 列，每格最多 128 个单行字符。单元格内可直接查看草稿，最终位置和字形以创建后的表格为准。
3. 点击“创建独立表格”。原文字层保留，Photoshop 会选中新建的“表格”智能对象。用移动工具调整位置，用自由变换调整大小。
4. 再次编辑时，选中表格，从 Caps 打开“文字源”。修改单元格后点“更新表格”。行列均分当前表框，更新沿用对象在画布上的位置和缩放。保存为分层 PSD 后可继续编辑。

## 操作

1. 面板读取所选文字。直接修改“编辑文字”，或选择“查找替换”“整理”“拆分”“列表”。266起，编辑区和下方预览都随可用宽度自动折行，长内容可以上下滚动。自动折行只改变显示，不添加换行符；Enter才会插入真实换行，并影响后续按行拆分。
2. 各页在修改内容或选项后自动计算并更新预览，无需点击计算；查找替换的匹配文字使用主题强调色。计算和继续编辑不修改 PS，改变文字或选项会立即使旧预览失效。
3. 确认画布草稿后，点击“生成矢量智能对象”或“更新矢量智能对象”。拆分页使用“拆成多个图层”单独输出。可用“将结果继续编辑”把处理结果作为下一次操作的草稿。
4. 关闭面板取消未提交草稿。“重新读取文字（覆盖草稿）”会用当前图层内容替换草稿。

| 功能 | 用法 |
| --- | --- |
| 编辑 | 修改文字后自动预览，确认后写回 |
| 普通替换 | 输入查找与替换内容；替换可留空，可选忽略大小写 |
| 正则替换 | 使用 Python 正则；例如查找 \d+ 替换数字，替换中的 \1 或 \g<名称> 引用捕获组 |
| 整理 | 去每行首尾空白、删空行、合并连续空格、指定连接符合并行、转大写／小写 |
| 列表 | 调整选中行层级，选择项目符号或编号样式；自动更新预览，保留空行 |
| 按行拆分 | 分组留空自动按实际行拆分；手填可合并连续行，如 1-3,4,5-7，须覆盖所有行 |
| 分隔符／正则拆分 | 不要求原文换行；例如用逗号或 [,，] 分隔，分隔符保留在前一组，纯空白组不单独生成图层 |

## 项目列表与编号列表

0.4.433 本机候选可直接从列表草稿生成或更新 Photoshop 原生 PDF 文字对象。选中对象后可通过 Caps 的“文字源”继续编辑。步骤、范围和旧版对象兼容性见[矢量文字对象](TEXT-VECTOR-OBJECTS.md)。

选择“列表”，再点“项目列表”“编号列表”或“移除列表”，结果会自动更新。283增加以下操作，公开状态见 [Wiki Versions](https://github.com/mianxiu/151500px-menu/wiki/Versions)：

1. 在编辑区选中需要调整的行，点击“增加缩进”或“减少缩进”，也可用 Tab／Shift+Tab。没有选区时作用于当前行，最多六级。软换行仍属于同一项。
2. 项目列表可按层级循环使用 `• ◦ ▪`，或固定圆点、圆圈、方块、短横、勾号及自定义单个符号。289候选仅对这些符号使用系统Segoe UI Symbol，正文保留原字体；确认前检查真实字形，不支持的自定义符号明确拒绝，不写入缺字方框。
3. 编号列表可选数字、括号数字、大小写字母、大小写罗马数字、`1.1` 分级编号或数字／字母／罗马数字混合层级。起始编号为1—9999，罗马数字不超过3999；下级在新的上级项目下从1重新开始。
4. 检查画布后点击“生成矢量智能对象”或“更新矢量智能对象”。“将结果继续编辑”可把结果放回编辑区，继续调整。

例如分级编号可生成：

```text
1. 第一项
    1.1. 子项
    1.2. 子项
2. 第二项
```

列表样式作用于整个正文；缩进按钮只作用于选中行或当前行。空行保留且不编号，已有常见标记会替换，重复应用不叠加。每级用四个空格记录层级，符号／编号和正文之间使用制表符。288／UXP0.3.86候选在确认时由PS测量前缀，并写入真实段落悬挂缩进；同级正文共用一列，自动续行对齐正文，移除列表恢复写入前的段落缩进。当前需要水平、左对齐的普通文字；沿用原文本框，空间不足时需先扩大文本框。结果仍是可编辑文字层，PS中按回车不自动续号；继续在本窗口的“列表”页编辑并确认即可重新编号。面板结果是内容预览，不是PS字形和文本框的准确预览。289／UXP0.3.89候选修复符号缺字，旧版已生成的列表需在此页重新确认写回一次。候选与公开下载的区别见版本状态。

285／UXP0.3.81起，确认列表时把符号／编号选项随原生文字层保存。保存PSD后，重新打开同一文字层的文本工具，会恢复列表页和选项；改名、同文档／跨文档复制保持。“将结果继续编辑”保留尚未确认的列表选项，PS原生修改后的正文仍以最新读取为准。移除列表清理本工具标记，不清理其他插件数据。仍从Caps打开，双击保持PS原行为；[数据、撤销与实测边界](TEXT-LIST-OBJECTS.md)。

## 实时匹配与正则范围

277起，全部文本页在停止输入约180毫秒后开始本地计算；查找内容或分隔符／正则为空时等待输入；按行分组为空则自动分组。查找替换沿用275的匹配强调色。上方原文仍可编辑，下面的“匹配”区以主题强调色显示完整匹配，下方结果区同步更新。原文／结果均软换行，零宽匹配计数但没有字符可着色；非法表达式／替换引用或超时显示错误，不能确认旧结果。原计算尚未结束时继续输入，只在完成后计算最新草稿，不并发积压，也不自动写回PS。180毫秒是合并输入的静置时间，不是保证的完整出结果时间。

使用内置Python3.11标准库`re.compile`／`finditer`和`Match.expand`，不是另写的简化正则。Unicode字符串语法由该版本引擎处理，支持数字／命名分组、反向引用、固定宽度后查找、前瞻、条件分组、原子组、占有量词及内联标志，例如`(?m)`、`(?s)`、`(?x)`。替换支持`\1`、`\g<名称>`和`\g<0>`；普通替换不解释反斜杠。输入表达式时直接填写，不加Python的引号或`r`前缀。

这不是Python整个`re`编程接口：不执行替换回调、Python代码或bytes模式；不提供`pos/endpos`、替换次数等API参数。不是第三方`regex`库，不支持它的Unicode属性等扩展，也不自动获得新Python版本新增的语法。PS换行在处理草稿时统一为LF、写回时转为PS段落符；空结果与现有长度／时间保护仍保持。语法以[Python3.11官方说明](https://docs.python.org/3.11/library/re.html)为准。

## 拆分排列

“保留位置”沿用已有换行边界，核验独立文字的字形和位置。“逐行排列”先把分组排成新行，再拆出独立图层；沿用文字的段落设置与变换，不承诺保留拆分前的原画面。

没有换行的文字请选择“逐行排列”。目前不支持把任意词语或字符在原单行中的位置精确拆成独立层；“保留位置”遇到这种边界会拒绝，不会静默改变布局。

## 字形边界读取与两种排列

276／UXP0.3.78起，测量副本保持可见但完全透明，不再依赖隐藏副本提供新字形边界；从副本读取完整文字的有效边界，结束前恢复并读回原透明度与可见性。边界支持明确的像素／点单位，点按文档分辨率换算；缺失、未知单位或无效边界仍拒绝，不用猜测值继续操作。错误附测量阶段、单位与DPI。

“逐行排列”允许重新排版，使用保留真实文字的前缀测量位置，不再经过空格副本的宽高校验；保持横向锚点与段落设置。竖排文字不开放这条路径。“保留位置”继续严格核验字形尺寸与位置，未通过时提示可改用逐行排列，不放宽阈值或把失败改成成功。原目标、样式、图层顺序、一次撤销及失败恢复核验保持，新增透明度／可见性恢复核验。

当前升级需要正常重启PS并确认实际加载UXP0.3.80（包含276的边界修复）；后台在旧执行端上会于发布修改前拒绝拆分，不能只替换主程序。该版本的本机PS24.0.1接口对照已覆盖点文字、段落折行、居中、72／300DPI、低CPU／正常配置及非默认透明度，8组均与预期渲染像素一致并一次撤销恢复；字形边界缺失与点单位分支另有模型回归，其他PS版本和截图所指电脑未实测。不声明性能提升。

## 自动预览和确认按钮

修改后停顿180毫秒自动计算，计算期间可以继续编辑，旧草稿结果不会写回。首次使用需要初始化，后续复用独立计算进程。

“写回当前文字”写入上方正文并保留原图层，不要求拆分分组有效。查找替换、整理或列表有有效结果时，按钮明确变为“写回预览结果”，写入下方结果。拆分页另有“拆成多个图层”，只有当前拆分预览有效才可使用；错误只影响该动作。

按行分组留空会根据当前草稿的真实换行更新，64行以内默认每行一层，更多行自动合并为最多64组。手填 `1-2,3` 等表达式才采用自定义分组，清空恢复自动。屏幕自动折行不增加行数；拆分仍需至少两组非空文字。没有换行的原文默认逐行排列，也可手动更改布局。

[281速度对照和测试边界](TEXT-PREVIEW-PERFORMANCE.md)；282调整操作逻辑，没有新增速度提升声明。

## 基线单位兼容

280／UXP0.3.80修正“无法核对文字基线”：测量支持描述中明确的点／像素单位，并按当前文档DPI换算，保留零、正负及混合基线偏移。样式读回按相同物理偏移比较，单位换算仅允许0.0001像素浮点误差；其他样式字段和原有字形／位置检查保持。未知单位、无效数值或不能核对的结果仍拒绝，并核验回滚。参考[Adobe基线说明](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/classes/characterstyle)。

## 样式、撤销和限制

286修复确认写回时的1460／SendMessageTimeout焦点交接错误。菜单请求交还PS后，根据实际前台状态继续；关闭面板、切换目标／会话或转到其他应用时仍拒绝。若提示“菜单尚未将焦点交回PS，本次未执行”，先激活PS并重新检查草稿后再确认；不会自动重发原写入。该修复沿用UXP0.3.81，无需为此重启PS。

确认前重新核验文档、单选图层、原文字和样式。未改动文字按差异映射保留样式，插入／替换内容沿用修改起点样式；整段重排、重复文字的手工编辑可能产生不符合预期的样式归属，建议分步处理并检查结果。颜色、字体、段落、抗锯齿和位置均按对应操作读回核验。拆分保持父组和连续层序。一次确认对应一个历史步骤，可一次撤销；失败尝试回滚，恢复未知时保留原请求，不自动重发。

新处理计划的读取窗口为30分钟，旧字面替换接口仍为60秒。任何实际内容、样式、名称、选择或会话变化仍会拒绝写入；延长编辑时间不减少写前校验。

上限20,000 UTF-16单位、1,024段样式、512KB样式数据、查找／分隔符200单位、替换500单位、拆分64组。空结果、缺失字体、手动字距和不完整样式会拒绝。拆分仍不支持路径／弯曲文字、剪贴、图层效果、多栏、竖排段落和溢出文本。

正则和草稿差异在 PS 外的独立进程计算，超过2秒就停止该计算，不提交 PS。这个期限包含计算进程启动；复杂表达式或复杂长文差异可能被拒绝。Python 正则与 JavaScript 正则语法不同，不能直接保证其他软件中的表达式通用。

## 编辑区软换行的实现
