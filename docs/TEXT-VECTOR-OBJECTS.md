# 可重新编辑的矢量文字对象

矢量文字对象在 Photoshop 中可以移动和缩放，保存为分层 PSD 后可从“文字源”继续编辑。正式下载与验证范围以 Wiki Versions 为准。

287／UXP0.3.82在现有Caps文本工具中增加矢量输出：用嵌入式PDF智能对象显示文字，在同一图层的自有元数据中保存可编辑正文、字符／段落样式、文本框、分辨率及列表选项。无需安装Illustrator，也不依赖外部缓存恢复正文。公开与实际运行状态见[Wiki Versions](https://github.com/mianxiu/151500px-menu/wiki/Versions)。

从 Caps 的“文字源”直接进入画布排版，可以在排除当前对象的画布背景上编辑正文，再用左侧的“字符”和“段落”修改文字选区、当前段落或整层。窗口显示本地草稿，最终换行和字形以 Photoshop 的输出为准。关闭窗口会丢弃未提交的正文和样式。确认更新会同时保存原生 PDF 和随层文字源。[画布排版](TEXT-TOOLS.md#画布排版)

### 缩略图双击在 PS 24.0.1 上的限制

在 Photoshop 中双击智能对象缩略图会打开其内容。UXP 的动作通知接口只提供事件名和描述符，没有公开的取消参数。Windows 的 MSAA 和 UI Automation 也未能识别此版本 Photoshop 的独立缩略图区域。当前从 Caps 的“文字源”重新编辑。

## 生成

1. 在 RGB／8 位文档中单选未锁定的普通文字层，从 Caps 打开“画布排版”。
2. 编辑正文或检查处理结果，点击“生成矢量智能对象”。有效处理结果优先，未选用处理结果时生成当前正文。Photoshop 原生排版导出 PDF，保留字体、字符／段落样式和文本框。
   从 0.4.433 本机候选起，列表草稿可直接生成矢量智能对象。Photoshop 先测量符号和编号的宽度，再将结果用于草稿预览和写回。
3. 等待确认完成。原文字层在同一位置和父组内替换为一个嵌入式矢量智能对象，保留名称、可见状态及颜色标签。一次撤销恢复原文字与元数据。

生成只在明确确认时执行。Photoshop 24.0.1 对符合条件的 RGB 8 位文档原位导出，覆盖已保存和从未保存的文档。紧凑 PDF 按点文字的可见字形或段落文字框确定页面，并保留文字在原稿中的位置。切到其他历史状态、历史空间不足或宿主不支持原位导出时，确认使用隔离渲染文档，完成后核对文档集合与活动图层。

## 重新编辑

选中对象，打开 Caps“文字源”。面板读取对象携带的正文和列表选项，修改后点击“更新矢量智能对象”。更新前核对真实目标、源数据和当前嵌入矢量的校验值。若显示内容曾被其他方式改动，工具会提示重新核对来源。带有本工具文字源的智能对象才支持此操作。

323候选继续识别旧版浏览器排版对象，并沿用其原排版器更新，避免仅因升级改变显示；此旧类型仍需要本机Edge，新生成的PS原生对象无需Edge。

0.4.458 起，Photoshop 24.0.1 对已核实独占嵌入内容的对象直接更新，沿用图层 ID 和实例变换。同一文档存在共享实例或无法核实独占时，通过独立副本替换选中的对象，其他实例保留原内容。独立替换后图层 ID 可能变化，继续编辑时重新读取当前选层。一次撤销恢复更新前的内容、选层和保存状态。

保存PSD后可重开继续编辑；改名、同文档复制及跨文档复制均携带源数据。原生导出智能对象的PDF内容不会带出图层XMP中的文字源，不能把单独导出的PDF当作可编辑备份。PSD是当前完整的保存载体。

PS原生双击仍按默认方式打开内容，尚不会打开本工具。对象内保留的是本工具可读写的文字／样式模型，不能把它描述为PSB内部的原生文字层。

## 范围与限制

- 支持 RGB 8 位、水平、未变形、单栏普通文字。带蒙版、图层效果、剪贴、非正常混合，或图层透明度／填充低于 100% 的源会被拒绝。对象可在 Photoshop 中移动和缩放，更新时核验变换。
- 紧凑页面的生成和再次编辑适用于已验证的 Photoshop 24.0.1。带透视的对象在新内容超出原 PDF 范围时需要先取消透视再更新。
- 保留已有文字样式，可在画布排版中调整字体、行距和段落。重新生成需要原字体与色彩配置可用。
- 沿用20,000 UTF-16单位与1,024样式范围的限制，源模型最多512KiB，XMP最多2Mi字符，画布最多6,400万像素，单份矢量内容最多16MiB。超限、损坏、冲突、未来版本或校验不符均拒绝。
- 矢量内容按目标大小重新渲染，PS文档与PNG仍受像素尺寸限制。已验证普通中英文字样本，不声明所有字体、效果或PS版本都能输出纯矢量或与原生文字逐像素相同。
- 水平、左对齐的列表草稿通过 Photoshop 原生测量生成悬挂缩进。同级正文和自动续行按同一正文列对齐。
- 失败核对回滚；结果或收尾未知时保留身份与证据，不自动重发。关闭面板不等于中断已开始的PS任务。

## 数据与执行

自有命名空间为`https://15100px.menu/ns/text-object/1.0/`。`source`保存模型及其SHA256，包含画布、完整文字描述和原文字层XMP；323新对象使用schema 1的PS原生排版，schema 2／list-v1仅用于兼容既有浏览器排版对象；`render`绑定当前嵌入PDF的SHA256。模型按UTF-16核验范围，保留混合及未知样式字段；拒绝DTD／实体、重复标记、无效JSON、危险对象键、路径／执行目标及非有限数值。不执行元数据中的代码。

源与显示在同一PSD图层中携带。单独把模型写入PDF的自定义元数据不够：本机PS嵌入PDF时会清除该数据，因此实际使用图层XMP。元数据只在明确打开与写前／写后读取，不增加菜单心跳查询；智能对象入口读取时再验证其所有权。

0.4.437 起，如果原字体缺少新输入的字形，且 Photoshop 换用了可用字体，文字源会记录实际使用字体的范围。保存 PSD 后重开，未改动的字形可继续使用已核验的回退。显式指定字体的范围仍严格校验，其他字符和段落属性继续逐项核对。

使用既有UXP持久请求与独立原生执行通道：UXP核对目标并保留执行槽位，原生脚本生成PDF并完成单历史事务，正常返回后记录匹配的执行退出凭据，UXP再核对源与实际选择。原生收据单独落盘不算脚本已退出。修改未知不调用另一条写入路径、不重放原请求。

紧凑页面在图层 XMP 的 `pageBounds` 中记录原稿坐标。更新先按当前实例变换换算页面中心，再由 Photoshop 替换 PDF 并核对四角。旧对象继续读取完整画布坐标。字体、样式、文本框和锚点在生成时读回，恢复或文档集合不符时保留未知。
