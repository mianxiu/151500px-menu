# 可重新编辑的矢量文字对象

327包含323已验证的PS原生排版生成与独立更新。以下保留287的局部验证和历史限制；完整排版编辑器、双击接管及无感写回仍未实现。正式下载与验证范围以Wiki Versions为准。

287／UXP0.3.82在现有Caps文本工具中增加矢量输出：用嵌入式PDF智能对象显示文字，在同一图层的自有元数据中保存可编辑正文、字符／段落样式、文本框、分辨率及列表选项。无需安装Illustrator，也不依赖外部缓存恢复正文。公开与实际运行状态见[Wiki Versions](https://github.com/mianxiu/151500px-menu/wiki/Versions)。

这是独立排版工作区的承载部分。独立画布页、字体／行距／段落控件和双击打开本工具尚未实现；当前面板仍是内容草稿预览，不是PS排版效果。

## 生成

1. 在RGB／8位文档中单选未锁定的普通文字层，打开Caps“文本工具”。
2. 编辑正文或检查有效处理结果，点击“生成矢量文字对象”。已有有效结果时生成该结果，否则生成当前正文；不会把失败的处理当成成功。323候选的新对象由PS原生排版导出PDF，保留字符／段落样式和文本框，不经过浏览器重新换行。
   列表选项发生改变时，先“写回预览结果”，重新打开文本工具，再生成对象；候选会拒绝把尚未写回的列表直接转换，以免使用旧缩进。
3. 等待确认完成。原文字层在同一位置和父组内替换为一个嵌入式矢量智能对象，保留名称、可见状态及颜色标签。一次撤销恢复原文字与元数据。

生成只在明确确认时执行。输入与本地内容预览不生成PDF、不连续写PS；确认时使用自建生成文档，完成后关闭并核对文档集合。它不启用已停用的图层缩略图回退。

## 重新编辑

选中对象，打开Caps“文字源”。面板读取对象携带的正文和列表选项，修改后点击“更新矢量文字对象”。更新前核对真实目标、源数据和当前嵌入矢量的校验值；若显示内容曾被其他方式改动，拒绝用旧文字源覆盖。普通智能对象没有本工具的源数据，会明确拒绝，不修改它。

323候选继续识别旧版浏览器排版对象，并沿用其原排版器更新，避免仅因升级改变显示；此旧类型仍需要本机Edge，新生成的PS原生对象无需Edge。

更新通过独立副本替换所选对象，核验原实例变换，保留其他复制实例的内容。更新后图层ID可能变化，后续读取使用新的实际选择；不依赖名称或旧ID找回对象。一次撤销恢复更新前对象。

保存PSD后可重开继续编辑；改名、同文档复制及跨文档复制均携带源数据。原生导出智能对象的PDF内容不会带出图层XMP中的文字源，不能把单独导出的PDF当作可编辑备份。PSD是当前完整的保存载体。

PS原生双击仍按默认方式打开内容，尚不会打开本工具。对象内保留的是本工具可读写的文字／样式模型，不能把它描述为PSB内部的原生文字层。

## 范围与限制

- 当前源限RGB8、水平、未变形、单栏普通文字；不接受手动字偶距、蒙版、图层效果、剪贴、非正常混合或图层透明度／填充不为100%的源。路径、弯曲、竖排或其他未支持布局拒绝生成。对象生成后可以在PS中移动和缩放，更新时核验变换。
- 保留已有文字样式，不增加字体／行距／段落选项的编辑控件。缺失字体不自动替换，重新生成需要对应字体与色彩配置可用；不安装或下载字体。
- 沿用20,000 UTF-16单位与1,024样式范围的限制，源模型最多512KiB，XMP最多2Mi字符，画布最多6,400万像素，单份矢量内容最多16MiB。超限、损坏、冲突、未来版本或校验不符均拒绝。
- 矢量内容按目标大小重新渲染，PS文档与PNG仍受像素尺寸限制。已验证普通中英文字样本，不声明所有字体、效果或PS版本都能输出纯矢量或与原生文字逐像素相同。
- 列表沿用原段落设置；PS自动续行的悬挂缩进仍待实现。生成矢量对象不会自动修正已有列表排版。
- 失败核对回滚；结果或收尾未知时保留身份与证据，不自动重发。关闭面板不等于中断已开始的PS任务。

## 数据与执行

自有命名空间为`https://15100px.menu/ns/text-object/1.0/`。`source`保存模型及其SHA256，包含画布、完整文字描述和原文字层XMP；323新对象使用schema 1的PS原生排版，schema 2／list-v1仅用于兼容既有浏览器排版对象；`render`绑定当前嵌入PDF的SHA256。模型按UTF-16核验范围，保留混合及未知样式字段；拒绝DTD／实体、重复标记、无效JSON、危险对象键、路径／执行目标及非有限数值。不执行元数据中的代码。

源与显示在同一PSD图层中携带。单独把模型写入PDF的自定义元数据不够：本机PS嵌入PDF时会清除该数据，因此实际使用图层XMP。元数据只在明确打开与写前／写后读取，不增加菜单心跳查询；智能对象入口读取时再验证其所有权。

使用既有UXP持久请求与独立原生执行通道：UXP核对目标并保留执行槽位，原生脚本生成PDF并完成单历史事务，正常返回后记录匹配的执行退出凭据，UXP再核对源与实际选择。原生收据单独落盘不算脚本已退出。修改未知不调用另一条写入路径、不重放原请求。

PDF以完整画布裁剪，放置后核对四角并修正原生像素偏移；字体、样式、文本框和锚点先在生成文档中读回。仅关闭本次返回了明确新身份的生成文档；文档集合或恢复不符时保留未知。
