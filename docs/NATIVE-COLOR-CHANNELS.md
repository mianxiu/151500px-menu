# CMYK／Lab／灰度原生数值

颜色面板可以编辑 PS 填充／描边描述中保存的原生颜色通道，保持文档的颜色模式、位深和 ICC 配置。327／UXP103包含已验证的326原生数值功能；公开下载以 Wiki Versions 为准，验证范围见本文末尾。

## 操作

1. 在 RGB、CMYK、Lab 或灰度的8／16位文档中，单选未锁定的形状或普通填充层，打开 Caps 颜色面板。
2. 原生 CMYK 显示 C／M／Y／K，Lab 显示 L*／a*／b*，灰度显示原始百分比。拖动数值或双击输入，支持小数，Lab 支持负值。模型以 PS 实际保存的颜色描述为准；例如 CMYK 文档中的 RGB 源颜色仍显示其原始 RGB 数值，不猜测转换成 CMYK。
3. 渐变先选择节点，再编辑该节点的原生数值或位置。非 RGB 渐变条只表示节点位置，不模拟颜色和插值效果；以 PS 画布为准。
4. 调整先保留为本地草稿。使用原来的确认操作写入，一次撤销恢复；Esc／右键取消未提交草稿，不修改 PS。

CMYK 和灰度范围为0至100，Lab 为 L* 0至100、a*／b* −128至127。原始数值随读取保存，显示格式不自行改写原稿。

## 范围

- 不将文档转成 RGB，不更换或分配 ICC，不经过应用工作空间进行颜色往返。
- 非 RGB 文档和原生颜色先使用本地草稿，不启用未验证的实时预览。RGB 文档中现有 RGB 颜色保留原取色器和预览能力。
- 原生模式不提供 HSV／Hex、屏幕取色和黑白快捷转换；形状外观剪贴板仍限原来的 RGB 范围。填充／描边切换、交换和原有蒙版控件保留。
- 32位／HDR、位图、索引、多通道及未知颜色描述保持不支持。目标、锁定、输入、焦点、忙碌、写前版本与写后读回保护保持；失败核对回滚，结果未知不重发。

## 验证状态

实际326／UXP103、PS24.0.1在双逻辑处理器／Below Normal与正常配置各通过三种模式的8／16位原生数值读取、写入及一次撤销，共12组；每种模式8位另核对渐变和启用描边，共6组。文档模式、位深与配置保持，原稿历史未变，隔离文档正常关闭，配置及CPU资源恢复。CMYK配置为U.S. Web Coated (SWOP) v2，灰度为Dot Gain 20%，Lab未分配配置；不将这些样本算作所有自定义ICC或16位渐变实测。

参数边界、渐变节点与中点保持、配置变更失鲜、回滚与未知保护专项通过。原生自测验证小数、Lab负值、双击输入、模型保持及既有输入／焦点／取消矩阵；当前浅灰主题的三档字号已核对。用户已确认326的Caps能正常打开。颜色写入验证通过真实PS接口执行，实体颜色控件点击与画布目视、其他PS及真实低配电脑仍待验，不以离屏图代替实屏。

首次形状写入会补建原本不存在的禁用描边；仅允许该确定的初始化，已有描边仍严格校验。灰度写入63.5时PS读回63.499999046325684，按原有0.01通道容差核验，不改写读取的原始精度。首轮准备脚本编译拒绝、缺省描边校验及严格浮点断言失败均保留；证据位于`.runtime/color-modes-326/`，最终验收ID为`3f427ab2947543169b149eb49903f07e`。

技术限制依据：[Adobe颜色转换API](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/photoshopcore)使用应用颜色设置，不能把它当作嵌入ICC转换；本实现直接保留原生通道，不调用该转换。
