# 独立渐变编辑窗口

已有渐变填充及形状渐变可在独立、可调整大小的 Windows 原生窗口编辑。选中一个包含自定色标渐变的图层，打开 Caps 颜色面板，再点击色条右侧的「打开独立渐变编辑」图标。有未确认调整时，点同一图标会先确认 Caps 的当前调整，再打开对应的填充或描边。确认的 Caps 调整和之后应用的独立窗口调整各有一次撤销。

窗口打开时按 Caps 所在屏幕的工作区定位，时间轴默认显示 0–100%。最小尺寸为 580×480 逻辑像素，按屏幕缩放换算。所有控件在窗口内显示，无需滚动。

上轨是不透明度节点，下轨是色标。单击轨道空白处立即在该位置添加节点，也可以使用添加按钮。按 Ctrl 点选、按 Shift 选取同一轨的连续节点，或从空白处拖动框选。拖动选中的节点可以一起移动，所选节点之间的间距保持一致。选中节点后可编辑位置、中点、颜色或不透明度。

RGB 渐变的参数区右侧常驻 Caps 同款取色器，包含饱和度／明度方块、色相条和感知配色点。点击色标就能直接调色。多选时，取色器以最后点击的已选色标为起点，调出的颜色应用到已选色标。CMYK、Lab 和灰度继续使用原生通道数值。

滚轮以指针位置为中心缩放时间轴。中键拖动、Shift 加滚轮或底部滑条可以平移。点击缩放百分比恢复全览。样式区的「缩放」改变 Photoshop 中的实际渐变大小。

窗口显示「实时更新 PS」时，拖动节点会预览到 Photoshop 画布。点「应用」确认，整次编辑合并为一个撤销步骤。点击右上角关闭图标「关闭并保留草稿」或按 Esc 会恢复 Photoshop 中的原渐变，下次在同一图层和同一原渐变上打开时可继续编辑。

切到其他应用时，实时预览恢复原渐变，草稿保留。编辑窗口和渐变条仍随 PS 显示，被其他窗口正常遮挡。最小化 Photoshop 时一并隐藏，回到原工作区后可继续编辑。关闭原 Photoshop 工作区会一并关闭编辑窗口并保留草稿。草稿存放在本机服务数据目录。未保存文档的草稿与当前 Photoshop 会话绑定。

支持单层、已有的自定色标渐变。非 RGB 通道使用文档原生数值。窗口标为「确认后更新 PS」时，点应用才写入 Photoshop。噪点渐变、预设库、渐变映射、图层样式及画布取样拟合见 [TODO](https://github.com/mianxiu/151500px-menu/blob/master/TODO.md)。

## 时间轴、类型与方向

拖动顶部文档名区域移动窗口，拖动边框调整大小。时间轴上方的「−／百分比／+」用于缩小、恢复全览和放大。刻度密度随轨道宽度与缩放调整。0.4.344 起，轨道下方的细全览条固定显示全部色标在 0–100% 中的位置。放大后，全览条突出当前可见区，拖动可见区可平移。切换到 100% 时下方控件保持原位。

参数区直接选择线性、径向、角度、对称或菱形。拖动方向盘调整角度，按 Shift 吸附到 45° 的倍数，也可在旁边直接输入角度。

349 开发候选按类型显示参数，最小窗口调整为 580×510 逻辑像素以容纳中心控件。径向使用“半径缩放”，角度渐变使用“起始角度”，线性、对称和菱形使用“方向”。半径缩放对应 Photoshop 的渐变缩放百分比，不是像素半径；角度渐变不显示无效的缩放控件。

“中心 X／Y”使用 Photoshop 原生偏移百分比，0% 表示原点，正值向右／下移动。“与图层对齐”决定原点参照图层还是文档。切换类型保留未显示的参数。旧草稿恢复时从原渐变补齐中心位置，不把已经移动的渐变重置到中心。候选验证与实际入口状态见 RELEASES，公开版本以 Wiki Versions 为准。

## 独立窗口与画布叠加

默认打开「独立窗口」。选中「画布叠加」后，渐变条显示在 Photoshop 画布上。可沿条拖动色标、不透明度节点与中点，也可调整中心、方向和范围。紧凑面板提供应用、模式切换和增删节点。点「独立窗口」可回到双轨、完整参数和取色器。两种模式共用草稿，切换本身不会应用修改或增加撤销步骤。

画布叠加期间，Photoshop 的工具栏和文字、数字、符号等编辑键暂停，Delete、退格和 Enter 也受保护。按住空格可平移，按 Z 可使用缩放工具，滚轮和滚动条仍可导航。Print Screen、Win＋Shift＋S、功能键和 Windows 系统组合键可用。切到其他应用后可以正常输入。在 Photoshop 画布上按 Esc，或点紧凑面板右上角的关闭按钮，即可退出渐变编辑、保留草稿并恢复正常操作。

径向用半径控制范围，角度渐变用圆环分布节点并拖动起始方向，对称和菱形显示各自范围。非 RGB 渐变条只表示节点和范围，在独立窗口可编辑原生通道值。缩放、滚动或平移时，渐变条随 Photoshop 返回的视图位置更新。导航期间节点让出鼠标，视图对齐后可继续拖动。若暂时无法核对位置，叠加模式保留草稿，可以继续操作画布或切回独立窗口。渐变条和控制柄只用于编辑。
