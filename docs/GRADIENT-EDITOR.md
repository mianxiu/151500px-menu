# 独立渐变编辑窗口

已有渐变填充及形状渐变可在独立、可调整大小的 Windows 原生窗口编辑。选中一个包含自定色标渐变的图层，打开 Caps 颜色面板，再点击色条右侧的「打开独立渐变编辑」图标。有未确认调整时，点同一图标会先确认 Caps 的当前调整，再打开对应的填充或描边。确认的 Caps 调整和之后应用的独立窗口调整各有一次撤销。

窗口打开时按 Caps 所在屏幕的工作区定位，时间轴默认显示 0–100%。最小尺寸为 550×450 逻辑像素，按屏幕缩放换算。所有控件在窗口内显示，无需滚动。

上轨是不透明度节点，下轨是色标。单击轨道空白处立即在该位置添加节点，也可以使用添加按钮。按 Ctrl 点选、按 Shift 选取同一轨的连续节点，或从空白处拖动框选。拖动选中的节点可以一起移动，所选节点之间的间距保持一致。选中节点后可编辑位置、中点、颜色或不透明度。

RGB 渐变的参数区右侧常驻 Caps 同款取色器，包含饱和度／明度方块、色相条和感知配色点。点击色标就能直接调色。多选时，取色器以最后点击的已选色标为起点，调出的颜色应用到已选色标。CMYK、Lab 和灰度继续使用原生通道数值。

滚轮以指针位置为中心缩放时间轴。拖动底部范围条的任一端可以缩放，另一端保持在原位置。拖动范围条中间、中键拖动或 Shift 加滚轮可以平移。点击缩放百分比恢复全览。样式区的「缩放」改变 Photoshop 中的实际渐变大小。

窗口显示「实时更新 PS」时，拖动节点会预览到 Photoshop 画布。Photoshop 忙于重绘时，编辑器只保留最新的待处理位置。松开鼠标后优先送出最后的位置，画面在 Photoshop 完成重绘后更新。点「应用」确认，整次编辑合并为一个撤销步骤。点击右上角关闭图标「关闭并保留草稿」或按 Esc 会恢复 Photoshop 中的原渐变，下次在同一图层和同一原渐变上打开时可继续编辑。

切到其他应用时，实时预览恢复原渐变，草稿保留。编辑窗口和渐变条仍随 PS 显示，被其他窗口正常遮挡。最小化 Photoshop 时一并隐藏，回到原工作区后可继续编辑。关闭原 Photoshop 工作区会一并关闭编辑窗口并保留草稿。草稿存放在本机服务数据目录。未保存文档的草稿与当前 Photoshop 会话绑定。

支持单层、已有的自定色标渐变。非 RGB 通道使用文档原生数值。窗口标为「确认后更新 PS」时，点应用才写入 Photoshop。噪点渐变、预设库、渐变映射、图层样式及画布取样拟合见 [TODO](https://github.com/mianxiu/151500px-menu/blob/master/TODO.md)。

## 时间轴、类型与方向

拖动顶部文档名区域移动窗口，拖动边框调整大小。时间轴上方的「−／百分比／+」用于缩小、恢复全览和放大。刻度密度随轨道宽度与缩放调整。0.4.344 起，轨道下方的细全览条固定显示全部色标在 0–100% 中的位置。放大后，全览条突出当前可见区，拖动可见区可平移。切换到 100% 时下方控件保持原位。

参数区直接选择线性、径向、角度、对称或菱形。拖动方向盘调整角度，按 Shift 吸附到 45° 的倍数，也可在旁边直接输入角度。

349 开发候选按类型显示参数，最小窗口调整为 580×510 逻辑像素以容纳中心控件。径向使用“半径缩放”，角度渐变使用“起始角度”，线性、对称和菱形使用“方向”。半径缩放对应 Photoshop 的渐变缩放百分比，不是像素半径；角度渐变不显示无效的缩放控件。

“中心 X／Y”使用 Photoshop 原生偏移百分比，0% 表示原点，正值向右／下移动。“与图层对齐”决定原点参照图层还是文档。切换类型保留未显示的参数。旧草稿恢复时从原渐变补齐中心位置，不把已经移动的渐变重置到中心。候选验证与实际入口状态见 RELEASES，公开版本以 Wiki Versions 为准。

## 独立窗口与画布叠加

首次打开使用「独立窗口」。点击「独立窗口」或「画布叠加」会记住选择，下次打开和重启程序后都会沿用。当前画布无法叠加时暂用独立窗口，已保存的选择会保留。叠加模式下，双轨、刻度和全览条固定在视口底边，RGB 取色器固定在右下角。双轨与画布控制柄共用色标选区。画布上的渐变条还可调整中心、方向和范围。点「独立窗口」可回到完整参数。两种模式共用草稿，切换本身不会应用修改或增加撤销步骤。

画布叠加期间，Photoshop 的工具栏和文字、数字、符号等编辑键暂停，Delete、退格和 Enter 也受保护。画布导航可用滚轮，也可按住空格平移或按住 Z 缩放。松键后恢复编辑，视图稳定后恢复控件。Print Screen、Win＋Shift＋S、功能键和 Windows 系统组合键可用。切到其他应用后可以正常输入。在 Photoshop 画布上按 Esc，或点紧凑面板右上角的关闭按钮，即可退出渐变编辑、保留草稿并恢复正常操作。

叠加模式的底部工具排保留应用、模式、时间轴缩放、通道和节点操作。右下显示正在调色的色标位置。RGB 叠加时，单击渐变条及手柄之外的画布位置，可直接给当前色标取色。选中多个颜色色标时同步调色。只选中不透明度节点时，取色目标是离该节点最近的颜色色标。右下吸管可临时隐藏控制器取色，这种取色中可按 Esc 或右键取消。

按 F 可[聚焦所选图层](LAYER-FOCUS.md)。聚焦期间暂时隐藏渐变控件，结束后在当前视图恢复。已有实时渐变预览会先恢复原值，聚焦结束后继续预览草稿。

画布叠加编辑时，图层面板中已确认的目标行会临时加上绿色底色。「菜单设置 → 常用 → 渐变画布叠加」可变更颜色或关闭高亮，下次打开渐变编辑时生效。高亮沿用 Photoshop 已绘制的选中行范围，切回独立窗口、退出编辑或无法核对图层行时消失。颜色保存在本机菜单设置。

径向用半径控制范围，角度渐变用圆环分布节点并拖动起始方向，对称和菱形显示各自范围。非 RGB 渐变条只表示节点和范围，在独立窗口可编辑原生通道值。缩放、滚动或平移画布时，双轨、取色器和画布控制柄暂时隐藏。视图对齐后，双轨和取色器回到固定位置，画布控制柄回到渐变上的位置。若暂时无法核对位置，叠加模式保留草稿，可以继续操作画布或切回独立窗口。渐变条和控制柄只用于编辑。

安装多个 Photoshop 版本时，每次启动一个版本。叠加模式优先通过与当前 Photoshop 的可执行文件匹配的 COM 入口读取画布。该入口不可连接时，使用已核对的当前 UXP 会话读取位置。需要 COM 预览的旧版 Photoshop 仍需有效的 COM 登记。请使用 UXP 0.3.110。

在画布渐变条上点击彩色带添加色标，点击不透明度一侧的细轨添加不透明度节点。按 Ctrl 点选多个节点，按 Shift 在同一轨选择头尾之间的节点。拖动任一选中节点可一起移动。选中不透明度节点后，底部可批量调整数值。拖动中心旁的旋转手柄可改变方向，按 Shift 吸附到 45°。渐变控件以外的画布仍可直接取色。

需要指定 COM 默认版本时，打开后台「插件管理 → 插件与版本」，在目标版本旁点击「设为默认」。目标 Photoshop 可以保持关闭。后台会核对 Windows 的 COM 注册和启动路径，并提供「恢复原设置」。缺少有效 COM 注册的安装会列在清单中，可通过 Adobe 安装修复登记。
